# SmartTwin Data Contract

Dokumen ini mendefinisikan struktur data yang digunakan untuk komunikasi antara:

- Traffic Processing
- Forecasting
- Simulation
- Recommendation
- Backend API
- Frontend Dashboard

Tujuan utama data contract adalah menjaga agar perubahan implementasi internal tidak merusak komunikasi antar-komponen.
